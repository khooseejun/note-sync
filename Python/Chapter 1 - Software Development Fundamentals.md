## 3. Algorithms
- Step-by-step process to solve a problem.
- Features:
  - Finite instructions
  - Well-defined
  - Halts after solution
  - Solves a general class of problems
- Enables automation of problem-solving.

## 5. Software Development Life Cycle (SDLC)
1. **Planning** – Estimate cost and resources
2. **Requirement Gathering** – Understand client needs
3. **Analysis** – Clarify and validate requirements
4. **Design** – Define architecture and approach
5. **Development** – Longest phase; coding
6. **Testing** – Ensure product meets requirements
7. **Deployment** – Release to client
8. **Maintenance** – Ongoing support and updates

> ✅ **Testing early reduces costs significantly.**

## 7. Python Programming
### Why Python?
1. **Popularity** – Top language in TIOBE, PYPL, IEEE Spectrum rankings.
2. **Continuous Support** – Active community and updates.
3. **Readability** – Clean, human-like syntax.
4. **Simplicity** – Fewer lines of code than Java/C++.
5. **Flexibility** – Used by Google, NASA, Facebook, Netflix, etc.
6. **Free & Open Source** – Available via Python Software Foundation.
7. **Extensive Libraries** – Rich ecosystem for various domains.

### Key Features:
- High-level, general-purpose, interpreted, multi-paradigm.
- Supports OOP and procedural programming.
- Platform-independent.

## 8. Key Takeaways
- Software development is more than coding — it involves planning, design, testing, and maintenance.
- Python is a powerful, versatile language ideal for beginners and professionals alike.
- Understanding algorithms and the SDLC is crucial for building effective software.
